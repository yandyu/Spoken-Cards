# 更新日志

按版本倒序记录已发布的用户可见改动。版本号与 `sw.js` 的缓存版本保持一致；开发中的视觉微调合并记录，不逐次当作发布版本。

## v20 — 2026-09-28

### 新增

- 新增「进度」Tab：连续学习天数、本月打卡天数、可切换月份的打卡日历，以及可切换年份的学习足迹。
- 完成卡片评分后记录当天练习；1–5 张为轻量学习，6 张及以上为深度练习。记录保存在浏览器本地。
- 年度足迹用 28 列 × 4 行汇总全年日期，每格约 3–4 天，以该区间最高练习强度着色。

### 界面与交互

- 移除卡片正面的蓝色“开口提示”条，保留场景、中文题面与翻面操作说明；不修改卡片内容和学习记录。
- 按确认的原型调整浅蓝背景、玻璃卡片、字体、间距与日历色阶；统计模块与日历保持独立分区。
- 底部导航使用卡片、图书馆和脚印图标。
- 年份菜单改为自定义玻璃下拉：从按钮下方展开、跟随页面滚动，空间不足时列表内部滚动；窗口变化后不向上翻转。
- 菜单与年份按钮等宽，收紧选项留白，年份数字居中；移除选中勾号，保留蓝色高亮。
- 支持方向键、Home / End、Esc 等键盘操作，以及减少动态效果的系统偏好。

### 修复与兼容

- 连续学习数字改用 SVG 渐变文字，修复数字边缘被裁成直线的显示问题。
- 离线缓存升级至 v20，按精确资源版本匹配缓存，页面导航优先请求网络；离线时使用已有缓存。
- 保留现有 96 个 Topic、1,524 张卡片和浏览器内学习进度；不根据旧卡片熟练度虚构历史打卡。

### 验证与升级

- `node validate-decks.js`：卡组、资源引用及缓存版本校验。
- `node scripts/test-year-picker.js`：下拉方向、等宽定位、滚动跟随与短窗口回归测试。
- 已打开的旧页面需要联网刷新后才会载入新版；无需清空浏览器数据。不同浏览器或设备的学习记录不会自动同步。

本次基于此前的口语化与情境提示更新（提交 `538a2ae`）发布。该次卡组改动保持不变；此前没有独立更新日志，本文件从 v20 开始维护。
