# 口语卡 · 雅思口语深度突破

碎片化口语语料训练器。卡组结构与《雅思口语深度突破》目录一一对应（12 Parts / 96 Topics），打开即刷卡：**中文情境 → 尝试开口 → 翻面 → 听发音跟读 → 三档评分**，间隔重复排期。

## 使用

直接用浏览器打开 `index.html` 即可（无需服务器、无需网络，数据存在浏览器本地）。

## 装到手机（PWA，脱离电脑随时用）

本项目已是可安装的 PWA：托管到任意 https 静态空间后，手机 Safari 打开一次 →「添加到主屏幕」，即成为独立的离线 App，之后不联网、不依赖电脑也能用，学习进度存在手机本地。

### 用 GitHub Pages 托管（网页上传，零命令行）

1. 登录 [github.com](https://github.com)，点右上角 **New repository**，命名如 `spoken-cards`，选 **Public**（免费版 Pages 需公开仓库），Create。
2. 新仓库页面点 **uploading an existing file**，把 `spoken-cards` 文件夹里的**所有内容**（`index.html`、`sw.js`、`manifest.json`、四个图标、以及整个 `data/` 目录）拖进去上传，Commit。
   - 注意保留 `data/` 子目录结构；GitHub 网页支持直接拖拽整个文件夹。
3. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)`，Save。
4. 等约 1 分钟，得到地址 `https://<你的用户名>.github.io/spoken-cards/`。
5. 手机 Safari 打开该地址 → 分享按钮 → **添加到主屏幕**。完成。

更新卡组后：重新上传改动文件，并把 `sw.js` 顶部的 `CACHE` 版本号 +1（如 `v3`→`v4`），手机上重开一次 App 即会拉取新内容。

> iOS 提示：PWA 离线缓存需 iOS 16.4+；`localStorage` 里的学习进度在独立 App 模式下会长期保留。

### 版权提醒

GitHub 免费 Pages 需公开仓库，代码与卡组会公开可见。本卡组仅含口语语块、原创改写的释义与例句，不含书中成段原文，个人学习用途风险很低；但如需更私密，可改用带访问密码的 Cloudflare Pages，或手机本地静态服务器 App。

### 三种场景模式

| 模式 | 场景 | 行为 |
|------|------|------|
| 🤫 静音 | 排队、办公室 | 脑内检索，不出声；学过的卡进入「待开口」队列 |
| 🎧 耳机 | 公交、高铁 | 翻面自动朗读语块，可跟读 |
| 🗣 出声 | 午休、在家 | 优先清「待开口」欠账，出声跟读 |

### 评分标准

不是"认不认识"，而是**开口那一下的真实感受**：
- 说不出 → 10 分钟后本组重现，间隔清零，熟练度系数 −0.2
- 磕磕绊绊 → 间隔 ×1.2（至少明天），熟练度系数 −0.05
- 脱口而出 → 间隔 1 → 3 → ×熟练度系数（默认 2.3）递增，即约 1、3、7、16、37 天

按钮下方的小字实时显示这张卡评分后的下次复习时间。

## 拆书制卡（扩充卡组）

书是扫描版 PDF。给 Claude 发某个 Topic 的页面截图（或让 Claude Code 直接渲染 PDF 页），配合下面的提示词生成卡组 JSON，然后在 app「导入」页粘贴。

### 拆书提示词模板

```
你是口语卡片编辑。请阅读《雅思口语深度突破》Topic {N}（{话题名}）的这几页，
按以下规则输出卡组 JSON：

1. 只提取"要点聚焦"和"实用贴士"中高亮的口语语块（chunk），以及对话中
   加粗的高频表达。跳过完整对话正文。
2. 挑选标准：母语者高频、中国学习者"看得懂但想不到"的表达。
   不选难词，选 sort of / to be fair 这类语块。
3. 每张卡：
   - scene: 使用场景短标签（如"道别 · 朋友间"）
   - prompt: 目标句子的自然中文版，是"要说的话"而不是提问——它是逼人开口的
     信号，不是问题，所以不要加问号（除非目标英文本身就是疑问句，此时可
     加前缀"问对方："）。中文措辞尽量贴着目标英文的结构走，让学习者翻面时
     能对照"我说的 vs 地道的说法"。
     反例："说这附近交通经常很糟糕？"（开放提问，会激活学习者已有的
     The traffic is terrible here，而不是目标语块）
     正例："这附近（交通）经常会堵得很厉害。"（"会"暗示 can get，
     指向 It can get terrible around here.）
   - chunk: 英文语块本身（保持简短，一张卡一个语块）
   - note: 一句话用法说明（英式/美式、正式度、常见误区），用自己的话写
   - example: 原创例句（不要抄书里的对话，自己写一个自然的情境例句）
4. 一个 Topic 出 15–30 张卡。
5. 输出格式：
{"topic": {N}, "cards": [{"scene": "...", "prompt": "...", "chunk": "...", "note": "...", "example": "..."}]}
```

### 用 Claude Code 渲染书页

```bash
# 书页码 → PDF 页码：PDF 页 = 书页 + 11
# 例：Topic 57「抱怨」在书 P269 → PDF 第 280 页起
venv/bin/python3 -c "
import pypdfium2 as pdfium
pdf = pdfium.PdfDocument('雅思口语深度突破.pdf')
for i in range(279, 284):  # PDF 页码-1 起始
    pdf[i].render(scale=2.0).to_pil().save(f'pages/p{i+1:04d}.png')
"
```
