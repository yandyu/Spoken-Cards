# 口语卡 · 雅思口语深度突破

碎片化口语语料训练器。已内置《雅思口语深度突破》全书 **12 Parts / 96 Topics / 1,524 张卡片**，打开即刷卡：**中文情境 → 尝试开口 → 翻面 → 听发音跟读 → 三档评分**，间隔重复排期。

## 使用

直接用浏览器打开 `index.html` 即可（无需服务器、无需网络，数据存在浏览器本地）。

## 装到手机（PWA，脱离电脑随时用）

本项目已是可安装的 PWA：托管到任意 https 静态空间后，手机 Safari 打开一次 →「添加到主屏幕」，即成为独立的离线 App，之后不联网、不依赖电脑也能用，学习进度存在手机本地。

### 用 GitHub Pages 托管（网页上传，零命令行）

1. 登录 [github.com](https://github.com)，点右上角 **New repository**，命名如 `spoken-cards`，选 **Public**（免费版 Pages 需公开仓库），Create。
2. 新仓库页面点 **uploading an existing file**，把 `spoken-cards` 文件夹里的**所有内容**（`index.html`、`sw.js`、`manifest.json`、四个图标、以及整个 `data/` 目录）拖进去上传，Commit。
   - 注意保留 `data/` 子目录结构；GitHub 网页支持直接拖拽整个文件夹。
3. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)`，Save。
4. 等约 1 分钟，得到地址 `https://<你的用户名>.github.io/spoken-cards/`。
5. 手机 Safari 打开该地址 → 分享按钮 → **添加到主屏幕**。完成。

更新卡组后：重新上传改动文件，并把 `sw.js` 顶部的 `CACHE` 版本号 +1（如 `v5`→`v6`），手机联网重开一次 App 即会拉取新内容。

> iOS 提示：PWA 离线缓存需 iOS 16.4+；`localStorage` 里的学习进度在独立 App 模式下会长期保留。

### 三种场景模式

| 模式 | 场景 | 行为 |
|------|------|------|
| 🤫 静音 | 排队、办公室 | 脑内检索，不出声；学过的卡进入「待开口」队列 |
| 🎧 耳机 | 公交、高铁 | 翻面自动朗读语块，可跟读 |
| 🗣 出声 | 午休、在家 | 优先清「待开口」欠账，出声跟读 |

### 评分标准

不是"认不认识"，而是**开口那一下的真实感受**：
- 说不出 → 10 分钟后本组重现，间隔清零，熟练度系数 −0.2
- 磕磕绊绊 → 间隔 ×1.2（至少明天），熟练度系数 −0.05
- 脱口而出 → 间隔 1 → 3 → ×熟练度系数（默认 2.3）递增，即约 1、3、7、16、37 天

按钮下方的小字实时显示这张卡评分后的下次复习时间。

## 自定义卡组（可选）

全书卡组已经随项目内置，手机端不需要 AI 接口，也不需要逐个解锁 Topic。「导入」页只用于粘贴你自己制作或修改的 JSON 卡组；导入相同 Topic 时，自定义卡组会覆盖内置版本。

如果以后需要重新制作某个 Topic，可把书页交给 AI，配合下面的提示词生成卡组 JSON，再到 app「导入」页粘贴。

### 拆书提示词模板

```
你是口语卡片编辑。请阅读《雅思口语深度突破》Topic {N}（{话题名}）的这几页，
按以下规则输出卡组 JSON：

1. 只提取"要点聚焦"和"实用贴士"中高亮的口语语块（chunk），以及对话中
   加粗的高频表达。跳过完整对话正文。
2. 挑选标准：母语者高频、中国学习者"看得懂但想不到"的表达。
   不选难词，选 sort of / to be fair 这类语块。
3. 每张卡：
   - scene: 使用场景短标签（如"道别 · 朋友间"）
   - prompt: 目标英文的“结构对齐式自然直译”，是学习者需要说出的中文内容。
     翻译时遵守以下原则：
     1) 以目标英文为唯一语义来源，确保英中文信息一一对应，不增不减。
     2) 保留英文中的主语、人称、时间、时态含义、情态、否定、程度、条件、
        因果和转折等关键信息。
     3) 不添加英文中没有的时间、频率、情绪、场景、评价或修辞；不省略能够
        帮助学习者还原英文结构的信息。
     4) 尽量按照英文的信息顺序组织中文；可以为符合中文母语者的表达习惯
        适度调整词序，但不能改变句子的语义结构，也不能逐词硬译得生硬。
     5) 英文习语使用含义最接近的日常中文，不做生硬的字面翻译，也不扩写成
        另一种情境。
     6) prompt 只放目标句子的中文内容。语法提示、英美差异、易错点以及
        “不要说……”等教学说明全部放入 note。
     7) 如果目标英文本身是疑问句，中文也直接写成对应的疑问句；不要添加
        “问对方：”等英文中不存在的提示。如果目标英文不是疑问句，则不要
        把中文写成开放式问题。
     8) 完成后做反向检查：只看中文时，学习者应能较为唯一地还原目标英文，
        而不是说出另一句意思相近但结构不同的英语。
     反例：chunk 为 It can get terrible around here.，prompt 却写成
     “这附近交通很糟糕。”（丢失 can get 表达的可能性和变化过程）
     正例：“这附近的情况可能会变得很糟糕。”（保留 can get，同时符合中文习惯）
   - chunk: 英文语块本身（保持简短，一张卡一个语块）
   - note: 一句话用法说明（英式/美式、正式度、常见误区），用自己的话写
   - example: 原创例句（不要抄书里的对话，自己写一个自然的情境例句）
4. 一个 Topic 出 15–30 张卡。
5. 输出格式：
{"topic": {N}, "cards": [{"scene": "...", "prompt": "...", "chunk": "...", "note": "...", "example": "..."}]}
```

## 数据结构

- `data/toc.js` — 全书目录（12 Parts / 96 Topics）
- `data/deck-topic-01.js` 至 `data/deck-topic-96.js` — 全书内置卡组（共 1,524 张）
- 自定义导入的卡组存在浏览器 localStorage（`sc_decks_v1`），学习进度存在 `sc_state_v1`
- Topic 1–10 的既有卡片顺序保持不变，升级后原学习进度可以继续使用
