# 口语卡 · 雅思口语深度突破

碎片化口语语料训练器。已内置《雅思口语深度突破》全书 **12 Parts / 96 Topics / 1,524 张卡片**，打开即刷卡：**中文情境 → 尝试开口 → 翻面 → 听发音跟读 → 三档评分**，间隔重复排期。

当前版本：**v20**。新增进度看板并完善玻璃年份下拉交互，详见 [更新日志](CHANGELOG.md)。

## 使用

直接用浏览器打开 `index.html` 即可（无需服务器、无需网络，数据存在浏览器本地）。

### 进度页

底部「进度」Tab 提供整体学习打卡日历：完成卡片评分后会记录当天学习；当天完成 1–5 张卡显示为「轻量学习」，完成 6 张及以上升级为「深度练习」。页面支持切换月份和年份，并用连续学习天数、月度日历与年度学习足迹展示长期积累。

学习打卡数据和卡片进度一起保存在浏览器本地，不会上传到服务器。

进度页视觉按确认的 851 × 1847 原型制作，以 425.5 CSS 像素为设计宽度，小屏等比适配。专用样式位于 `progress.css`。系统状态栏、底部手势条由设备绘制。年度足迹采用 28 列 × 4 行的日期区间汇总（每格约 3–4 天），按列从上到下、从左到右覆盖全年，颜色表示区间内最高练习强度；每日详情以月历为准。旧版没有记录学习日期，历史打卡不会根据卡片熟练度倒推。

## 装到手机（PWA，脱离电脑随时用）

本项目已是可安装的 PWA：托管到任意 https 静态空间后，手机 Safari 打开一次 →「添加到主屏幕」，即成为独立的离线 App，之后不联网、不依赖电脑也能用，学习进度存在手机本地。

### 用 GitHub Pages 托管（网页上传，零命令行）

1. 登录 [github.com](https://github.com)，点右上角 **New repository**，命名如 `spoken-cards`，选 **Public**（免费版 Pages 需公开仓库），Create。
2. 新仓库页面点 **uploading an existing file**，把 `spoken-cards` 文件夹里的**所有内容**（`index.html`、`progress.css`、`sw.js`、`manifest.json`、四个图标、以及整个 `data/` 目录）拖进去上传，Commit。
   - 注意保留 `data/` 子目录结构；GitHub 网页支持直接拖拽整个文件夹。
3. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)`，Save。
4. 等约 1 分钟，得到地址 `https://<你的用户名>.github.io/spoken-cards/`。
5. 手机 Safari 打开该地址 → 分享按钮 → **添加到主屏幕**。完成。

更新后请联网刷新页面；已经打开的旧页面不会自动替换。无需清空浏览器数据，以免丢失本地学习记录。

## 发布维护

1. 将已确认的改动记录到 [CHANGELOG.md](CHANGELOG.md)，注明版本、日期与兼容性影响。
2. 同步递增 `sw.js` 中的缓存版本、缓存资源查询版本，以及 `index.html` 中的资源查询版本。
3. 在项目目录运行 `node validate-decks.js` 和 `node scripts/test-year-picker.js`。
4. 提交代码、样式、测试和更新日志。当前仓库的应用位于 `spoken-cards/` 子目录，发布时保留该目录结构。
5. 刷新实际使用的页面，检查进度页与年份下拉；不要用清空学习数据的方式更新。

> iOS 提示：PWA 离线缓存需 iOS 16.4+；`localStorage` 里的学习进度在独立 App 模式下会长期保留。

### 三种场景模式

| 模式 | 场景 | 行为 |
|------|------|------|
| 🤫 静音 | 排队、办公室 | 脑内检索，不出声；学过的卡进入「待开口」队列 |
| 🎧 耳机 | 公交、高铁 | 翻面自动朗读语块，可跟读 |
| 🗣 出声 | 午休、在家 | 优先清「待开口」欠账，出声跟读 |

### 评分标准

不是"认不认识"，而是**开口那一下的真实感受**：
- 说不出 → 10 分钟后本组重现，间隔清零，熟练度系数 −0.2
- 磕磕绊绊 → 间隔 ×1.2（至少明天），熟练度系数 −0.05
- 脱口而出 → 间隔 1 → 3 → ×熟练度系数（默认 2.3）递增，即约 1、3、7、16、37 天

按钮下方的小字实时显示这张卡评分后的下次复习时间。

## 数据结构

- `data/toc.js` — 全书目录（12 Parts / 96 Topics）
- `data/deck-topic-01.js` 至 `data/deck-topic-96.js` — 全书内置卡组（共 1,524 张）
- 学习进度存在浏览器 localStorage（`sc_state_v1`）
- Topic 1–10 的既有卡片顺序保持不变，升级后原学习进度可以继续使用

## 口语化与情境提示

- 卡片正面保留原有 Topic 分类、学习顺序、场景与中文题面，不再显示额外的蓝色“开口提示”条。
- 已将最容易造成直译、误用或过度书面化的 79 张卡改成更常见的日常口语表达；法律、政治、战争等主题保留必要概念，但优先使用能直接说出口的句型。
- `scripts/refresh-spoken-cards.js` 保存这次批量口语化替换规则，后续扩充语料时可以继续沿用同一套标准。
