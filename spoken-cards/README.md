# 口语卡 · 雅思口语深度突破

碎片化口语语料训练器。已内置《雅思口语深度突破》全书 **12 Parts / 96 Topics / 1,524 张卡片**，打开即刷卡：**中文情境 → 尝试开口 → 翻面 → 听发音跟读 → 三档评分**，间隔重复排期。

## 使用

直接用浏览器打开 `index.html` 即可（无需服务器、无需网络，数据存在浏览器本地）。

## 装到手机（PWA，脱离电脑随时用）

本项目已是可安装的 PWA：托管到任意 https 静态空间后，手机 Safari 打开一次 →「添加到主屏幕」，即成为独立的离线 App，之后不联网、不依赖电脑也能用，学习进度存在手机本地。

### 用 GitHub Pages 托管（网页上传，零命令行）

1. 登录 [github.com](https://github.com)，点右上角 **New repository**，命名如 `spoken-cards`，选 **Public**（免费版 Pages 需公开仓库），Create。
2. 新仓库页面点 **uploading an existing file**，把 `spoken-cards` 文件夹里的**所有内容**（`index.html`、`sw.js`、`manifest.json`、四个图标、以及整个 `data/` 目录）拖进去上传，Commit。
   - 注意保留 `data/` 子目录结构；GitHub 网页支持直接拖拽整个文件夹。
3. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)`，Save。
4. 等约 1 分钟，得到地址 `https://<你的用户名>.github.io/spoken-cards/`。
5. 手机 Safari 打开该地址 → 分享按钮 → **添加到主屏幕**。完成。

更新卡组后：重新上传改动文件，并把 `sw.js` 顶部的 `CACHE` 版本号 +1（如 `v5`→`v6`），手机联网重开一次 App 即会拉取新内容。

> iOS 提示：PWA 离线缓存需 iOS 16.4+；`localStorage` 里的学习进度在独立 App 模式下会长期保留。

### 三种场景模式

| 模式 | 场景 | 行为 |
|------|------|------|
| 🤫 静音 | 排队、办公室 | 脑内检索，不出声；学过的卡进入「待开口」队列 |
| 🎧 耳机 | 公交、高铁 | 翻面自动朗读语块，可跟读 |
| 🗣 出声 | 午休、在家 | 优先清「待开口」欠账，出声跟读 |

### 评分标准

不是"认不认识"，而是**开口那一下的真实感受**：
- 说不出 → 10 分钟后本组重现，间隔清零，熟练度系数 −0.2
- 磕磕绊绊 → 间隔 ×1.2（至少明天），熟练度系数 −0.05
- 脱口而出 → 间隔 1 → 3 → ×熟练度系数（默认 2.3）递增，即约 1、3、7、16、37 天

按钮下方的小字实时显示这张卡评分后的下次复习时间。
